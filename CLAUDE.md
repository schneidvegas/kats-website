# kats-website

Single-file static site (`index.html`) for Lilac Kat Creatives, a pet/portrait/fantasy
art commission business. Deployed via GitHub Pages to `lilackatcreatives.com` (see
README.md for DNS setup). No build step, no backend, no framework — keep it that way
unless asked otherwise.

## Grooming this repo
When asked to groom/improve the site, check the "Grooming backlog" checklist in
README.md first and work down it, or look for the next highest-impact polish item:
copy quality, accessibility (contrast, focus states, alt text once real images land),
performance (image sizes/formats), SEO metadata, and mobile layout. Keep everything
in `index.html` unless a change genuinely requires splitting files (e.g. real photos
landing means adding an `/images` directory).

Don't invent content Kat hasn't provided (bio text, pricing, real artwork) — placeholder
copy should stay clearly a placeholder until replaced with real material.
